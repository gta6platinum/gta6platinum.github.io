GTA 6 Comics & Book Swap Locations

All comics and book swaps in GTA 6.

  1. Un Extraño RescateClimb one of the towers (some light parkour) and drop in through a roof hatch. Downstairs, a door asks for a code (it varies, always the digits 1-4). At the back is an operations room with a recording on a table next to a phone. All the buttons on the board must be blue. Don't take the middle door: there is only radiation behind it. Solving the puzzle frees an alien, who is beamed up to a UFO that then destroys the FIB cars. Part of a side mission: the code only works while it is active.Photo: Hugo Loera / GTABase📍 Map pin
